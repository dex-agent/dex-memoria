# Templates

Perfil destes artefatos: `legacy-v1`.

Os templates desta pasta representam a cadeia vigente `L1 -> L2 -> L3`. Eles
nao sao exemplos do layout `governed-theme-v2` e nao autorizam criar
`memorias/`, ligar L1 diretamente a L3 ou migrar memoria viva. A V2 permanece
`approved_not_active`; seus futuros templates exigem Trilho e aprovacao
separados.
