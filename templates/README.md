# Templates

Este catálogo é misto e declara o perfil de cada artefato.

- `l3-conhecimento-file.md` é o template canônico V2 para uma unidade direta
  `L1 <-> L3`, com `owner_skill` e sem L2 artificial.
- Os demais templates em camadas ainda preservam formatos históricos de
  compatibilidade `legacy-v1`, inclusive a cadeia `L1 -> L2 -> L3`; eles não
  definem o contrato ativo.

Dex Memória V2 é o writer ativo e usa exatamente uma rota bidirecional por
unidade: `L1 <-> L2` OU `L1 <-> L3`. Para uma unidade V2 nova, siga `SKILL.md`,
`SPEC.md` e `docs/memory-architecture-profiles.md`; não trate
`governed-theme-v2` como perfil de produto.
