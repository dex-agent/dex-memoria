## Objetivo

Guardar explicacao longa somente quando a investigacao pedir profundidade.

## Escopo

Este exemplo cobre a separacao entre gatilho curto, memoria operacional e
documentacao sob demanda.

## Modelo Operacional

Use L1 para lembrar que existe um caminho. Use L2 para agir. Abra L3 quando o
detalhe operacional ficaria longo demais no L2.

## Validacao

validar L1 -> L2, L2 -> L3 e L3 -> L2
