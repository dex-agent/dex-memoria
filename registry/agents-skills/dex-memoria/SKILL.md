# Dex Memória - Redirecionador Global

Este arquivo é somente uma ponte curta do registry global. Ele não replica o
contrato de memória.

## Destino Único

Abra a fonte canônica e comece pela seção `Entrada cotidiana`:

```text
C:\CodexProjetos\dex-memoria\SKILL.md
```

Ignore qualquer cópia alternativa de `dex-memoria`. Somente o destino acima
possui autoridade operacional.

Para gravação normal, use `dex-memoria v2 remember`; não carregue SPEC, usage,
runtime-boundary ou código de desenvolvimento. Consulte a seção de manutenção
da fonte canônica somente quando houver falha, recovery ou mudança de contrato.

## Falha Bloqueante

Se a fonte canônica estiver ausente ou ilegível, declare bloqueio explicito:

```text
Bloqueado: a fonte canônica C:\CodexProjetos\dex-memoria\SKILL.md não está disponível. Nenhuma rota alternativa é autorizada.
```

Não improvise contrato, não carregue outra fonte e não transforme este
redirecionador na skill completa.

## Atualização

Atualize primeiro a fonte completa no repositório canônico. Este redirecionador
só muda quando o caminho canônico ou o próprio contrato de redirecionamento
mudar. A instalação global exige backup, diff e validação.
